AgroRoute Stream
Aplicação desenvolvida para otimização, monitoramento e gerenciamento de rotas e dados em operações agrícolas.

Sobre o Projeto
O AgroRoute Stream é um projeto focado no setor do agronegócio para auxiliar no planejamento e acompanhamento de rotas de campo (como tratores, colheitadeiras e pulverizadores), permitindo a transmissão, processamento ou visualização contínua de dados de cobertura e logística agrícola.

Funcionalidades
Mapeamento de áreas e talhões agrícolas.

Planejamento e cálculo de rotas otimizadas para máquinas no campo.

Processamento e transmissão de dados em fluxo (stream) de telemetria ou navegação.

Visualização de trajetos e área coberta.

Exportação e integração de dados geográficos e logísticos.

Tecnologias Utilizadas
Linguagem / Runtime: Node.js / Python / TypeScript

Frameworks / Bibliotecas: FastAPI / Express / React / Next.js

Dados Geográficos e Stream: PostGIS / WebSockets / GeoJSON / Leaflet / Mapbox

Pré-requisitos
Antes de começar, certifique-se de ter instalado em sua máquina:

Node.js (versão 18 ou superior) ou Python (3.10 ou superior)

Docker e Docker Compose (caso utilize ambiente conteinerizado)

Git

Instalação e Execução
Clone o repositório:
git clone https://github.com/andrey-seg/Projeto-agroRoute-strem.git

Acesse o diretório do projeto:
cd Projeto-agroRoute-strem

Instale as dependências:

Para projetos em Node.js: npm install

Para projetos em Python: pip install -r requirements.txt

Inicie a aplicação:

Para ambiente com Docker: docker-compose up -d

Para execução direta: npm run dev ou python main.py

A aplicação estará disponível no endereço local configurado (por padrão http://localhost:3000 ou http://localhost:8000).
